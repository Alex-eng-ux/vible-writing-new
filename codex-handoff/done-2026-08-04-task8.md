4. LangSmith 不可用、超时或配额错误时业务不能失败或重复执行；
5. 使用 Fake model 和本地 fixture 完成评测，不要求真实 LangSmith API Key；

## 自动埋点接入（本轮补完）

- `TraceHook`/`RedactionHook` 接入 LangGraph 节点：三个图（场景/章节/Canon）都经
  `AgentCallable` + `HookRegistry` 执行节点，`register_trace(registry, sink)` 把
  `TraceHook` 注册到全部 7 类 Agent 即自动覆盖所有节点；
- 模型/工具调用：`trace_call(...)` 包装器自动上报 `llm`/`tool` 运行事件
  （节点名编码 `{node}:{kind}:{call}`，形成 generation_run -> agent_run ->
  llm/tool_run 层级）；
- 运行边界：`GraphObservability` 包装图 `invoke`，自动记录 `run_start`/`run_end`/
  `error`；`record_author_feedback` 记录作者反馈（只存哈希）；
- 所有内容进入 sink 前先经 `RedactionHook` 脱敏（默认 deny）；sink 调用防御性
  fail-open，观测失败不影响业务、不导致命令重复执行。

## 生产 wiring（本轮补完）

- `app/observability/wiring.py`：`make_wiring(cfg)` 按配置构建生产 sink
  （LangSmith 未启用/无 `LANGSMITH_API_KEY` 时只用本地 sink）；`get_default_wiring()`
  提供进程级默认装配；`ObservabilityWiring.traced(graph)` 幂等包装（同一图重复
  调用只注册/包装一次，防重复埋点与重复包装）；`traced_call` 为模型/工具调用
  生产入口；`record_feedback` 为作者反馈生产入口（fail-open）。
- Worker/运行入口：`worker_main` 启动时构建生产 wiring 并记录就绪；`RunExecutor`
  新增可选 `observability` 参数，传入时经 `traced(graph)` 把图包上
  `GraphObservability` 并注册 `TraceHook`（`GraphLike` 协议兼容三图与包装器）。
- 三图注册：`SceneGraph`/`ChapterGraph`/`CanonGraph` 各自持有 `HookRegistry`，
  `traced` 经只读 `registry` 属性为每张图的全部 Agent 节点注册 `TraceHook`
  （`register_trace` 覆盖 7 类 Agent）。
- 作者反馈决策入口：`submit_run_decision(..., sink=None)` 在 `decision="feedback"`
  分支调用 `record_author_feedback`（只存反馈哈希，正文不落库）；sink 缺省取
  进程级 wiring，显式注入便于测试；命令幂等由 `execute_command` 保证（重放返回
  首次响应，不重复执行），sink 失败 fail-open 不影响决策事务。

## 关键设计决策

1. **Task 4A 冻结类型只向后兼容追加**：`RunContext`/`NodeEvent`/`ErrorEvent` 用 `NotRequired` 追加 Task 8 字段（既有构造仍合法、无读者被破坏）；新增 `RunEndEvent`/`RunFeedback`；`TracePort`/`FakeTracePort` 未动。事件字段读取统一用 `.get()` 回退（`run_context` 与顶层字段两种形状都兼容）。
2. **默认 deny 脱敏 + 白名单**：sink 只接收脱敏副本；除结构化白名单（ID/状态/枚举/时间戳/数值）外任何字符串替换为 `[redacted]`；列表元素继承父键。`capture_content` 仅 `development/evaluation` 可开启（与 `config.py` fail-closed 校验一致），生产即使开关为真也拒绝启动。脱敏失败 fail-closed：记录降级而非保存原文。
3. **fail-open + 幂等 sink**：`LangSmithSink` 捕获一切异常并分类降级（不保存原始异常消息，避免内容泄漏），绝不向业务抛出；同一事件重试不重复调用外部 API（先去重再发送）。`FallbackSink` 把 primary 失败写入本地降级记录，业务结果与执行次数不受影响。
4. **评测不依赖真实 API Key**：`evaluate_fixture` 在本地 fixture 上确定性运行；`run_evaluation(source="langsmith-dataset", langsmith_client=None)` 自动降级本地并标记 `degraded=True`，同一组样例仍可评测。报告每项指标都带样本数/分母/公式/阈值/基线，不只一个百分比。
5. **发布门槛**：结构化输出合法率与版本提交正确率 100%，未授权 Canon 写入 0，脱敏泄漏 0，重复/丢失事件与版本 0，规则误报率 <=5%（>=30 条负例），一次修订成功率 >=80%（>=20 样例）。fixture 数据全部满足门槛（17/20 修订 = 85%）。
6. **不修改业务契约**：未改动正文、Canon、版本与运行状态机任何代码；observability 事件仅追加字段；本地 sink 为结构化日志 + 内存记录，未新增 DB 表（不替代 `RunEvent`/`RunDecision`/版本/checkpoint）。
7. **自动埋点零侵入接入**：不修改任何 agent 图与执行器的行为。三个图（场景/章节/Canon）都经 `AgentCallable` + `HookRegistry` 执行节点，`register_trace` 注册一个 `TraceHook` 即覆盖全部节点；`GraphObservability` 以同接口包装 `invoke`（run_start/run_end/error）；模型/工具调用由 `trace_call` 包装（不改变返回值与异常语义）。节点事件名编码 `{node}:{kind}:{call}`，形成 generation_run -> agent_run -> llm/tool_run 层级。
8. **内容进入 sink 前双重保障**：`RedactionHook` 构造时只提取结构化元数据（输入版本/清单来源），不采集内容键；`trace_call` 的输出摘要只含调用名与状态；LocalSink/LangSmithSink 再整体 `redact_payload` 兜底。错误消息键不在白名单内，进 sink 前同样被脱敏。
9. **sink 故障防御性 fail-open（不重复执行）**：`TraceHook`/`trace_call`/`GraphObservability` 对 sink 调用做防御性 try/except，即使注入一个完全抛错的 sink（违反 fail-open 约定），图照常完成、业务结果不变、图只执行一次，降级被记录在钩子/包装器上。
10. **生产 wiring 幂等接入（防重复包装/埋点/执行）**：`ObservabilityWiring.traced` 以图/注册表上的标记属性保证同一图只包装一次、同一 `HookRegistry` 只注册一次 TraceHook；三图仅新增只读 `registry` 属性、`RunExecutor` 仅新增可选 `observability` 参数（不传时行为不变，向后兼容）；`submit_run_decision` 仅新增可选 `sink` 参数，feedback 分支记录反馈哈希；命令幂等由 `execute_command`（重放首次响应）与 sink 幂等去重共同保证，sink 失败绝不触发命令重复执行。`make_wiring` 在 `langsmith_tracing` 与 `langsmith_api_key` 同时配置时才启用 LangSmith，否则只用本地 sink（不要求真实 API Key）。

## 范围边界

- **自动埋点已接入生产 wiring**：`worker_main` 启动构建生产 wiring；`RunExecutor` 经可选 `observability` 参数自动包装图；`traced` 为三图注册 TraceHook；`submit_run_decision` feedback 分支调用 `record_author_feedback`；模型/工具调用经 `traced_call`（当前 Agent 均为占位/Fake 实现，真实 LLM 调用在 Task 9 接入后经同一入口产生 llm/tool 事件）。三图仅新增只读 `registry` 属性、执行器仅新增可选参数，未改变任何图/状态机/提交语义。
- **本地 sink 未持久化到 DB**：结构化日志 + 内存记录，进程重启丢失；未新增观测表（避免引入迁移与契约变化）。生产持久化可后续加观测表，不改变既有 `RunEvent`/`RunDecision`/版本/checkpoint 契约。
- **真实 LangSmith 发送未线上验证**：适配器按 `langsmith.Client.create_run(name, inputs, run_type, project_name=...)` 契约调用；无 Key 时 `client=None` 跳过，评测自动降级本地，业务不受影响。
- **feedback 自动记录已接线**：`submit_run_decision`（feedback 分支）调用 `record_author_feedback` 只存哈希；`resume`/Canon 决策路径不产生作者反馈事件（Canon 反馈恢复留给 Task 9 决策层接线）。
