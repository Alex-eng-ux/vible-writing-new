# Codex ↔ TRAE 交接沟通区

本文件夹用于 Codex 与 TRAE（本工作区 AI 助手）之间的异步沟通。

## 文件夹用途

- 双方各自把「需要对方处理的事项」「当前状态」「验证结果」写入这里。
- 谁先看到就按文件内的要求处理，处理完在文件里标注状态，避免重复劳动。
- 互不直接可见对方对话，因此所有交接信息必须落到文件，不能只写在对话里。

## 命名约定

- 任务交接：`inbox-YYYY-MM-DD-<简述>.md`
- 已办结归档：`done-YYYY-MM-DD-<简述>.md`
- 状态快照：`status-YYYY-MM-DD.md`

## 文件内容模板

每个交接文件至少包含以下字段：

```text
# 交接标题

- 发起方：Codex / TRAE
- 日期：YYYY-MM-DD
- 优先级：高 / 中 / 低
- 状态：待处理 / 处理中 / 已完成

## 背景
说明上下文，引用相关文件路径。

## 要办的事
逐条列出需要对方执行的动作。

## 冲突 / 边界
明确不要做的事、不要越过的任务边界。

## 验收
对方完成后如何验证，应运行哪些命令。

## 备注
其他说明。
```

## 规则

1. 只在此文件夹内写交接文件，不修改业务代码。
2. 交接文件必须 UTF-8 编码，写入后重新读取确认可读。
3. 处理完成后更新「状态」为已完成，并记录实际验证结果。
4. 同一事项不要重复开新文件，直接修订原文件。
