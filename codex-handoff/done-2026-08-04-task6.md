## 关键设计决策

1. **只读显式快照 + manifest**：`ConsistencySnapshot` 显式携带已冻结版本内容
   （人物/地点/时间线/硬规则/术语/正文）与 `snapshot_revision_ids`；规则绝不
   读取当前最新版本。证据引用一律取自 `ContextManifest` 已登记来源
   （`_manifest_source_ids`），禁止引用草稿或未授权来源；manifest 无匹配来源时
   evidence 为空，`validate_review_issue` 会拒绝该问题进入自动修订。
2. **ReviewIssue 强契约**：`ReviewIssue` 的 severity 限定
   low|medium|high|critical（与 Task 4A `RuleIssue` 的 low|medium|high|blocking
   是两套独立类型），status 限定 pending|accepted|rejected|deferred。每条问题
   必须带 `local_key`、`severity`、`dimension`、`text_locator`（quote 或
   char_start/char_end 或结构化锚点）、`evidence_refs`、`message`、`suggested_fix`。
3. **稳定合并指纹**：`merge_review_issues` 按
   `local_key + dimension + text_locator + evidence_refs` 计算 SHA-256 指纹；
   同指纹问题只保留既有条目（保留其历史处理状态），不生成第二条等价问题；
   message/suggested_fix/status 变化不算新问题。
4. **严重级别路由**：`route_review_issues` 固定规则——任一 high|critical 问题
   → `waiting_feedback`（必须转作者反馈，规则服务绝不直接提交版本）；无问题 →
   `accepted`；全部 low|medium 时 `scene_auto_revision_count==0` → `auto_revision`
   （计数 +1，当前运行内最多一次），已 >=1 → `waiting_feedback`。人工反馈创建
   新动作但不重置该计数（计数由运行时持久化，本服务为纯函数不落库）。
5. **确定性规则实现**（全部子串/正则/编辑距离，不接模型 API）：
   - 人物存在性（medium）：草稿中行动者（`{名}{动词}` 模式）不在已知名单
     （快照人物 + manifest 登记实体名）内 → 未知人物；
   - 死亡/离场状态（high）：`state=dead|departed|absent` 的人物在草稿中再次
     出现并行动；
   - 地点可达性（high）：`{人物}抵达/来到{地点}` 且目标地点 `reachable_from`
     不包含人物最近地点；
   - 时间线先后（high）：草稿时间标记早于快照时间线已发生的最新事件时间
     （`第N章/第N日/第N年/N年后/N年前` 归一为可比较数值）；
   - 世界硬规则（critical）：草稿命中规则 `forbidden_patterns`；
   - 术语一致性（low）：草稿出现规范术语的形近变体（编辑距离 ≤1）且不在
     允许变体名单内。
6. **无证据/无定位拒绝**：`validate_review_issue` 在规则执行后与路由前两处
   调用；缺少证据（无依据指控）、缺少正文定位、证据引用未登记来源、非法
   severity/dimension/local_key/message/suggested_fix 均抛 ValueError，阻断
   进入自动修订。
7. **Task 4A 契约零改动**：`RuleEngineInput`/`RuleIssue`/`RuleEngineOutput`/
   `RuleEngine`/`MinimalRuleEngine`/`build_rule_engine` 原样保留；`schemas.py`
   仅追加新类型；未修改任何 Agent/运行/Canon/API 代码。

新增测试覆盖用户要求：

1. 人物已死亡后再次行动（`dimension=state`、`severity=high`、local_key 含 dead）。
2. 地点不可能到达（`dimension=location`、`severity=high`）；可达地点不误报。
3. 时间线先后冲突（`dimension=timeline`、`severity=high`）；不早于最新事件时不误报。
4. 术语变体（`dimension=term`、`severity=low`）；已登记变体不误报。
5. 无依据指控（`evidence_refs=[]` 被 `validate_review_issue` 拒绝）。
6. 缺失定位或证据（空 `text_locator` / 空证据被拒绝；`route_review_issues` 前校验阻断）。
7. 相同问题稳定合并（同指纹只保留一条且保留历史状态；不同问题不合并）。
8. 高风险问题阻止自动修订（high/critical → `waiting_feedback`，计数不递增）。
9. 低风险问题最多自动修订一次（count=0 → auto_revision 且计数 +1；count>=1 → waiting_feedback）。
10. 规则结果不写入 Canon（规则/服务调用后 `CanonFact` 计数不变；规则函数无 session 依赖）。
11. 补充：世界硬规则违反（critical）、未知人物存在性（medium）、规则确定性输出、
    可序列化、配置开关关闭维度、ReviewIssue 全字段契约、证据引用未登记来源拒绝、
    非法 severity（blocking 被拒）/dimension/local_key/message/suggested_fix 拒绝、
    结构化定位（paragraph_ref/anchor_id）被接受。
