# 资源右键删除设计

## 范围

项目、卷、章节、场景和右侧版本历史中的单条版本都支持右键删除。删除入口统一显示为上下文菜单中的“删除”，执行前必须二次确认。

## 行为

- 删除项目、卷、章节或场景时，后端显式删除其所有后代资源及关联运行、草稿、版本和审计数据；删除在一个事务内完成。
- 删除版本时，只删除目标场景版本及其不再被引用的关联对象；如果版本被当前 accepted 指针或其他业务记录引用，返回可读错误，前端保留列表并显示错误。
- 删除当前选中的场景或其所属祖先时，前端清空编辑区、版本历史和比较状态。
- 删除成功后只刷新受影响的树节点或版本列表，不重新加载无关资源。
- 右键菜单支持鼠标右键和键盘焦点，点击菜单外部或按 Escape 关闭。

## 错误与安全

所有删除请求携带唯一 `Idempotency-Key`。后端拒绝不存在资源和受保护版本，删除失败不提交部分结果；前端显示后端错误消息。

## 验证

后端测试覆盖删除项目层级和版本引用保护；Playwright 测试覆盖右键打开菜单、确认删除和列表刷新。
